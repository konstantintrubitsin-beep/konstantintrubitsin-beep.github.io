# site — копия coslovs.com

Рабочая копия сайта-референса на Astro. Отсюда будем переделывать под Костю.

**Контент пока чужой** — тексты и картинки Елены Козловой, медиа тянется с её CDN.
Это черновик-референс, публиковать в таком виде нельзя. Перед деплоем весь контент
заменяется на свой.

## Запуск

```bash
npm --prefix portfolio-ai-creators/site run dev
```

Откроется на `localhost:4330` (конфиг `coslovs-copy` в `~/AgentData/.claude/launch.json`).
Сборка статики — `npm run build`, результат в `dist/`.

## Как это устроено

Оригинал собран в Readymag: абсолютное позиционирование на холсте 1024 px (телефон — 320 px),
холст масштабируется под ширину окна. Копия повторяет ту же механику, но данные лежат отдельно
от кода, поэтому контент можно менять, не трогая вёрстку.

```
reference/coslovs/data/*.json   сырая выгрузка виджетов Readymag
        ↓  npm run data  (scripts/build-data.mjs)
src/data/pages/*.json           нормализованные страницы: виджеты, координаты, готовый HTML текста
        ↓  astro build
dist/                           24 статические страницы
```

| Файл | Что делает |
|---|---|
| `scripts/build-data.mjs` | нормализатор: Draft.js-текст → HTML, координаты, кроп картинок, анимации, стили ссылок |
| `src/pages/[...slug].astro` | генерит все страницы из `src/data/pages` |
| `src/components/Widget.astro` | рендер одного виджета: текст, линия, прямоугольник, картинка, слайдшоу, видео |
| `src/styles/global.css` | холст, масштаб, типографика, телефонный брейкпоинт |
| `src/styles/links.css` | генерится автоматически из стилей ссылок проекта — руками не править |
| `public/viewer.js` | масштаб холста, слайдшоу, анимации (load / hover / click / scroll) |

Разбор оригинала — в `docs/REF-COSLOVS.md`.

## Что заменено

**Шрифт.** Оригинал использует Pragmatica Condensed через Adobe Fonts — она платная, и её
веб-файлы отдаются по лицензии Adobe, скачать их «просто так» нельзя. Взят **Roboto Flex**:
переменная гарнитура с осью ширины и полной кириллицей, ось `wdth` подогнана под метрики
Pragmatica (строки ломаются в тех же местах, что в оригинале).

Менять шрифт — две строки в `src/styles/global.css`:

```css
--f-cond: 'Roboto Flex', sans-serif;
--cond-wdth: 79;
```

Если купишь Pragmatica Condensed (Paratype / Adobe Fonts) — подставь её сюда и убери `--cond-wdth`.

Pinyon Script, League Gothic и Meow Script свободные, тянутся с Google Fonts.

**Медиа.** Картинки хотлинкаются с `i-p.rmcdn.net` с параметрами ресайза и кропа.
Работает, пока их CDN отвечает; это временно, до подстановки своих файлов.

## Что не перенесено

- **Видео** (38 штук). HLS-плейлисты лежат на закрытом хосте Readymag и отдают 403 — на их месте
  серые плашки. Проигрыватель написан и заработает, как только подставим свои файлы.
- **Мобильное меню.** Оверлей по кнопке «Menu» скрыт: пункты меню лежат в отдельном слое
  `aboveAllWidgets`, который в выгрузку страниц не попадает. Десктоп не затронут.
- **Строка «☆★ All Works ★☆»** переносится на две строки: звёзды берутся из системного
  шрифта и шире оригинальных. Косметика, чинится подбором символьного шрифта.
